# Mamboleo

Mamboleo is a public safety web app for Kenya that helps people see and share real-time incident information.

## What It Does

- Shows a live map of reported safety incidents and alerts.
- Lets people submit incident reports from the public interface.
- Supports community corroboration ("I see this too") to strengthen trust in reports.
- Surfaces media and social-source updates in one place.

## How It Works (Simple)

1. Community members and source feeds provide incident information.
2. The backend validates, enriches, and stores reports in WordPress.
3. The frontend app displays incidents, advisories, and updates on an interactive map.
4. Moderation and review tools help maintain quality and reduce noise.

## Why It Matters

Mamboleo can help communities, responders, journalists, and local organizations:

- spot emerging risks faster,
- coordinate safer movement,
- improve situational awareness,
- and build a shared public record of local incidents.

## Public and Community Potential

With broader community participation, Mamboleo can evolve into:

- a stronger civic early-warning network,
- a useful source for local resilience planning,
- and a collaborative open data layer for safety insights.
